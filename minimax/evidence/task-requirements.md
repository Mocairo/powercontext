## 其他已核对约束

- 分支/commit 必须基于官方 `2026-competition-ecosystem`；作品资产全部放在根目录 `minimax/`。
- MiniMax 必须参与实际代码生成或修改；seekdb/OceanBase 必须实际提供工程资料查询；PowerContext 必须实际保存并复用任务进展或验证结果。仅安装、测通连接或文档提及均不满足要求。
- 模块可以采用 SDK、HTTP、MCP 或插件，必须给出调用入口、输入输出以及实际方式和版本。
- 测试失败不能是缺依赖、无法启动等环境错误；修改前后测试集必须一致，不能删除断言、跳过测试或调整预期来造通过。
- 必交完整源码、运行说明、验证样例、代码快照与差异、功能及回归日志、三项技术使用记录、一页技术说明。
- 日志包含命令、退出码和代码版本。配置示例仅占位值，不提交真实凭据，不要求提交模型私有思维链。
- 评审从干净环境复现，以平台固定提交和实际运行结果为准；截图不可替代源码和复现步骤。
- MiniMax 不要求重新生成完全相同的补丁；上下文不要求措辞或排序一致，但必要内容和来源必须正确。
- 基础状态复用不要求恢复完整 Agent 会话；扩展能力不额外计分。
